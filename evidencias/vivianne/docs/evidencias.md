# Evidências Sprint 1

## D-1 - Diagrama de Linhagem de Dados

### Objetivo

Representar visualmente o fluxo completo dos dados do processo de registro de usuários, desde a origem até armazenamento, auditoria, monitoramento e observabilidade.

### Atividades Realizadas

- Análise do README do projeto.
- Investigação da infraestrutura Docker.
- Análise do endpoint `/auth/register`.
- Identificação do uso de bcrypt.
- Identificação do PostgreSQL.
- Mapeamento do fluxo de dados.
- Criação do Diagrama de Linhagem de Dados.

### Arquivos Entregues

- lineage-diagram.png

### Resultado

O diagrama apresenta o fluxo completo dos dados de registro de usuários, incluindo processamento, segurança, armazenamento, auditoria, observabilidade e tratamento de falhas.
