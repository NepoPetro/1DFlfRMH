# Proyecto: 1DflfRMH - Ecosistema NepoPetro

#ES
## Presentación del Proyecto

Esta plataforma es un caso de estudio de ingeniería que demuestra el ciclo completo del dato: desde la autenticación de usuarios hasta la observabilidad y la analítica. No es un simple sistema de login, sino una arquitectura diseñada para la escalabilidad, la calidad y la gobernanza de datos.

**Objetivo:** Construir un sistema de identidad que genere datos valiosos para la toma de decisiones, integrando desarrollo backend, automatización de pruebas, monitoreo y visualización analítica.

**Enfoque Estratégico:** El proyecto orbita en torno al Quality Assurance (QA) y la Automatización de Pruebas. Gastón, como QA Lead y Product Owner, lidera la estrategia de calidad, gestiona el backlog y asegura que cada entrega cumpla con los criterios de aceptación. El diseño de la plataforma prioriza la testabilidad, la trazabilidad y la generación de métricas de calidad desde el día uno.

#PT
## Apresentação do Projeto

Esta plataforma é um caso de estudo de engenharia que demonstra o ciclo completo do dado: desde a autenticação de usuários até a observabilidade e a analítica. Não é um simples sistema de login, mas uma arquitetura projetada para escalabilidade, qualidade e governança de dados.

**Objetivo:** Construir um sistema de identidade que gere dados valiosos para a tomada de decisões, integrando desenvolvimento backend, automação de testes, monitoramento e visualização analítica.

**Abordagem Estratégica:** O projeto orbita em torno do Quality Assurance (QA) e da Automação de Testes. Gastón, como QA Lead e Product Owner, lidera a estratégia de qualidade, gerencia o backlog e garante que cada entrega atenda aos critérios de aceitação. O design da plataforma prioriza a testabilidade, a rastreabilidade e a geração de métricas de qualidade desde o primeiro dia.

## Tecnologías Utilizadas

- **Backend:** Node.js, Express, JWT, bcrypt
- **Base de Datos:** PostgreSQL
- **Infraestructura:** Docker, Docker Compose
- **Testing:** Mocha, Chai, Playwright, Newman, Pact
- **CI/CD:** GitHub Actions
- **Observabilidad:** Grafana, Looker Studio
- **Visual Analytics:** Google Looker Studio, Power BI (próximamente)
